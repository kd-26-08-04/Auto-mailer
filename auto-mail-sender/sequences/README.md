# Apollo.io collab sequences — Fit with Reshmi

These **are cold emails**. Brands skip most of them. The rewrite below is built so a marketing / founder inbox has a reason to reply, not a reason to archive.

## Fill these in before you send

Replace in every file (or Apollo custom fields):

| Apollo variable | Maps to |
|---|---|
| `{{first_name}}` | Contact first name |
| `{{company}}` | Brand / company / agency name |

Without numbers, the mail still looks like every other creator pitch. With numbers, it looks like a small media buy.

## Why brands reply (or skip)

They skip: “I create content, let’s collab.”  
They reply when they see: **right audience + proof + a tiny first step + an easy yes.**

First step in these mails: **gifted product + 2 reels they can reuse as UGC** (ads, website, Amazon). That is cheaper and faster for them than a big paid campaign.

## How to load in Apollo

1. One sequence per niche, 5 automatic emails.
2. Delay: **3 days** between steps.
3. Send from **colaabwithreshmi@gmail.com**.
4. Mail 1 subject should **not** all start the same — Apollo / Gmail will flag templates.

## Files

One markdown file per niche in this folder, plus:

- `agency-owners.md` — 5-mail sequence for **agency owners** (influencer / UGC / performance) whose clients are in those same niches. Pitch is a paid 2-reel test they can forward to a client, not a free-product ask. CTA: Yes / Interested, then **roster** on Mail 5.
